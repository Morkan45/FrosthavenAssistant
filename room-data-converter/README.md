# Archived room-data converter

This directory is retained as historical source material only. It has no
supported command-line entry point, its Dart SDK constraint predates the active
application, and its checked-in JSON is not the source of the app's packaged
room data.

Do not use it to generate or replace files under
`frosthaven_assistant/assets/data`. Any future revival needs a separately
reviewed specification, a current Dart toolchain, an explicit input/output
contract, and fixture-based compatibility tests against the app's data model.
